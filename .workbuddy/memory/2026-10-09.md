## InputCard.jsx 环境变量 404 修复
- **现象**：`fetch("/undefined/api/analyze")` POST 404，console 报 chrome-extension 噪音但和本 bug 无关。
- **根因**：`backend/.env.local` 里的 `NEXT_PUBLIC_API_BASE_URL` 不会被 Next.js 读到——Next.js 只加载**项目根目录**下的 `.env.local`，前端那份根本不存在。
- **修复**：
  1. 新建 `F:\project\zero-to-tech\.env.local`，写 `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000`。
  2. `InputCard.jsx` 给 `API` 加 `|| "http://localhost:8000"` 兜底；同步把"暂时写死在下面"那句过时注释改成事实描述。
- **未做的事**：第 3 个冗余的 `onSubmit={preventDefault}`（按钮已 `type="button"`）—— 用户没明确要改，遵循最小改动原则暂不动。
- **提醒用户**：改完 `.env.local` 必须**重启** `npm run dev`，`NEXT_PUBLIC_*` 在 HMR 阶段不会自动刷新。
